Кнопки

Описание

Кнопка — это базовый элемент интерфейса, используемый для отправки данных или выполнения действий пользователем.

Состояния

  • Обычное: Основное состояние кнопки.
  • Наведение: Состояние при наведении курсора.
  • Активное: Состояние при нажатии на кнопку.
  • Неактивное (disabled): Состояние, когда кнопка не может быть нажата.

Пример использования

<button class="btn-primary">Отправить</button>

Стили

.btn-primary {
  background-color: var(--primary-color);
  color: white;
  border-radius: 4px;
  padding: 10px 20px;
  font-size: 16px;
  cursor: pointer;
}

.btn-primary:hover {
  background-color: var(--primary-color-hover);
}

.btn-primary:disabled {
  background-color: var(--primary-color-disabled);
  cursor: not-allowed;
}

Карточки

Описание

Карточка используется для отображения информации в компактном виде. Она может содержать текст, изображения, ссылки и другие элементы.

Пример использования

<div class="card">
  <img class="card-img" src="image.jpg" alt="Изображение карточки">
  <h3 class="card-title">Заголовок карточки</h3>
  <p class="card-description">Описание карточки...</p>
  <button class="btn-primary">Действие</button>
</div>

Стили

.card {
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 16px;
  background-color: var(--card-background);
}

.card-img {
  width: 100%;
  border-radius: 4px;
}

.card-title {
  font-size: 18px;
  color: var(--primary-color);
}

.card-description {
  font-size: 14px;
  color: var(--text-color);
}

.card .btn-primary {
  margin-top: 12px;
}

Формы

Описание

Форма используется для ввода данных пользователем. Это важный компонент для взаимодействия с пользователем.

Пример использования

<form action="#" method="POST">
  <label for="name">Имя:</label>
  <input type="text" id="name" name="name">
  <button type="submit">Отправить</button>
</form>

Иконки

Описание

Иконки служат для визуального представления действий, объектов или статусов. Их можно использовать в кнопках, меню и других элементах интерфейса.

Пример использования

<i class="icon-home"></i>
